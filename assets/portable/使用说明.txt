deskpet v0.2.0 测试版（便携版）

启动方式
1. 把整个压缩包解压到你自己的目录（不要在压缩包里直接运行）。
2. 双击本目录里的 deskpet.exe。
3. 不要单独移动 deskpet.exe；resources 文件夹必须和它放在一起。

第一次运行
- 角色会出现在桌面上，聊天条在立绘下方。
- 首次运行可能弹出 Windows SmartScreen：点“更多信息” → “仍要运行”。
- 可以在设置里配置模型，也可以把 .env.example 复制成 .env 后填写。
- ASR / TTS / 识图模型不随包内置；需要时在“主动陪伴 → 模型库”里下载或配置。
- 屏幕识图需要本机 Ollama 或 OpenAI 兼容视觉端点。

麦克风
- 首次使用语音前，Windows 会询问是否允许麦克风，请选“允许”。
- 设置 →“麦克风”可以查看授权状态，并打开 Windows 麦克风 / 声音设置。
- 如果提示 NotReadableError：先检查安全软件（本机已确认 Kaspersky 会拦截 Electron）并把 `electron.exe` / `deskpet.exe` 加入允许列表；再检查 Windows 声音设置里的默认麦克风、独占模式和格式。
- 默认使用 Chromium 麦克风（有回声消除和自动增益）。设置 →“后台引擎”的兼容模式才会启用 Windows 原生采集；它没有回声消除、会独占麦克风，切到微信等窗口时会释放，回到 deskpet 自动恢复。

角色包
- 设置 →“角色包”可以把当前角色导出为 zip，也可以导入别人分享的 zip。
- 同一个 char_id 默认保留两者并自动改名；只有明确选择“覆盖”才会替换角色包。
- 导出不包含记忆；导入缺部位框时只会提醒，不会自动生成。

数据与隐私
- 聊天记录、记忆和日志保存在 %APPDATA%\deskpet\data，不写入程序目录。
- 记忆库使用 SQLCipher 整库加密；原文在成功压缩后保留 7 天。
- “完全重置该角色记忆”会删除该角色的原文、事实、摘要、状态、观察和使用统计；角色包与人设不会被删除。

退出
- 关闭主窗只是隐藏到托盘；右键托盘图标可重新显示或退出。
- 首次运行如没有看到窗口，请检查系统托盘。
