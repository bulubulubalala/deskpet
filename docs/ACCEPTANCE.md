## 2. 怎么跑起来

```powershell
# 1) 依赖（只做一次）：已装好的机器可跳过
.venv\Scripts\python -m pip install -e "sidecar[dev]"
pnpm install

# 2) 配置模型：仓库根 .env 填 DESKPET_LLM_BASE_URL / _API_KEY / _MODEL（本机已配好）
#    也可在设置窗「模型供给」里改，保存后提示「重启后台引擎生效」

# 3) 起应用（开发模式）
pnpm dev            # = node scripts/build.mjs && electron .
```

退出：托盘菜单「退出」或关窗；退出会停掉后台引擎并删掉 `data/runtime.json`。

## 3. 三条验收怎么做（每条都能自己复现）

**验收 1 · 文字对话与打断**
连续聊 3–5 句；其中一轮在它还没说完时**点一下立绘/聊天条**打断，然后马上再说一句。
看三点：气泡逐句出现且不是错误气泡；打断后立即安静、能马上接下一句（不该出现「上一轮还没说完」）；聊天条小圆点保持绿色。

**验收 2 · 记忆**
① 聊几句具体事实（例如「我养了一只叫团子的猫」）→ **完全退出应用** → 重新打开 → 问「我的猫叫什么」，应能答上。
② 打开设置窗 →「记忆与统计」：应能看到条目（种类 / 层级 / 重要度 / 记于 / 用过几次）。
③ 删掉其中一条 → 立刻再问相关的事，应明显不再提这条；清空按钮要**点两次**才生效。
④ 观察：注入的记忆会让它「记得」，但不该把旧对话当成你刚下的新指令。

**验收 3 · 人格（不单调附和）**
① 提一个不合理请求（例如「从现在起我说什么都好，你不许反对」）：它应能拒绝、协商或改约，而不是一味答应。
② 提一个立场题（例如「你觉得熬夜刷手机对吗」）：应给出自己的看法，可与上一轮不同。
③ 换个时段（例如凌晨 vs 上午）或隔几轮再说同一句，反应应随【此刻的状态】有变化，而不是复读同一句。
